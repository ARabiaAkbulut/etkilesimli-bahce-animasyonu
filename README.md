# Etkileşimli Bahçe Animasyonu

## Proje Hakkında
Python ve Pygame kullanılarak geliştirilen
etkileşimli bir gece bahçesi animasyonudur.

## Özellikler
- Açılıp kapanabilen çiçekler
- Hareket eden ateş böcekleri
- Animasyonlu bulutlar
- Etkileşimli karahindibalar
- Uçuşan tohum animasyonları

## Kullanılan Teknolojiler
- Python
- Pygame
- Math
- Random

## Kullanım
Projeyi çalıştırmak için Python ve Pygame
kütüphanesinin kurulu olması gerekir.
